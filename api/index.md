# API

Довідник згенеровано з XML-коментарів у коді. Згенерований код (protobuf, gRPC, міграції EF Core) сюди не входить.

- `ContainerForest.Aggregator.Domain`: доменна модель центрального агрегатора.
- `ContainerForest.Aggregator.Application`: сервіси, команди, пайплайн деплою, порти.
- `ContainerForest.Aggregator.Infrastructure`: EF Core, git, з'єднання з агентами.
- `ContainerForest.Aggregator.Api`: REST і gRPC.
- `ContainerForest.Agent`: агент на хості.
- `ContainerForest.DiscordBot`: Discord-бот.
