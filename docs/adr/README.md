# Архітектурні рішення (ADR)

Короткі записи рішень, про які сперечались, з контекстом і відкинутими варіантами. Нове рішення, що змінює [перелік рішень](../design/decisions.md), оформлюється тут наступним номером.

| ADR | Рішення |
|---|---|
| [0001](0001-solution-structure.md) | Структура репозиторію і шари ЦА |
| [0002](0002-proto-contracts-layout.md) | Контракти: лише `.proto`-файли, пакети без префікса й версії |
| [0003](0003-secrets-at-rest.md) | Секрети в базі ЦА шифруються ASP.NET Core Data Protection |
| [0004](0004-stack-directory-in-place.md) | Каталог стеку не замінюється: файли пакета оновлюються на місці за маніфестом |
| [0005](0005-caddy-entry-point.md) | Єдиний вхід у систему — Caddy в образі панелі: SPA, `/api`, gRPC агентів і бота, автоматичний TLS |
| [0006](0006-git-connections.md) | Підключення до git-серверів: облікові дані й дозволені середовища — на підключенні; репозиторії під ним додають Editor |
| [0007](0007-api-tokens.md) | Персональні API-токени з обмеженнями (лише читання, середовища, строк); перевірка прав через `Actor` зі scope облікових даних |
| [0008](0008-cli.md) | CLI `forest`: вхід через браузер за device flow з loopback-сигналом, токен створюється лише при видачі; .NET + System.CommandLine + Kiota |
| [0009](0009-passwordless-sign-in.md) | Вхід без пароля: passkeys ASP.NET Core Identity .NET 10; вхід і прив'язка через Discord OAuth2 з `DiscordLink` як єдиною ідентичністю |
| [0010](0010-git-secrets-filter.md) | Git-фільтр для секретів SOPS: відкритий текст у клоні Editor'а, стандартні файли sops у git; ЦА розшифровує лише ключами середовищ, де людина — Editor, токену потрібен прапорець `secrets` |
| [0011](0011-signed-commits.md) | Засвідчення вмісту стеку підписами SSH комітів: ключі користувачів з обмеженою областю, перевірка до розшифрування секретів, нащадок розгорнутого коміту для автоматичних деплоїв, режим digest образів |
| [0012](0012-stack-isolation.md) | Ізоляція стеків на хості: роль «адміністратор середовища», політика compose за нормалізованою моделлю від агента з винятками й звільненням засвідченого вмісту, ключі SOPS на стек |
| [0013](0013-system-settings.md) | Налаштування системи: типізовані секції, пріоритет змінних середовища, секрети лише на запис, свіже підтвердження особи для чутливих змін |
| [0014](0014-aggregator-backup.md) | Необов'язковий бекап ЦА: зашифрований на офлайн-ключ архів бази й key ring у S3-сумісному бакеті, уточнення інваріанта 1 |
| [0015](0015-image-updates.md) | Запропоновано: оновлення образів самою ЦА за політикою стеку, коміт у репозиторій стеку, засвідчення через засвідчений батьківський коміт, явний запит тегу із закріпленням |
